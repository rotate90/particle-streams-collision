# Столкновение двух потоков частиц

Интерактивная браузерная симуляция столкновений двух потоков твёрдых дисков. Синие частицы потока A и красные частицы потока B рождаются в двух источниках, движутся с настраиваемыми скоростью и разбросом и сталкиваются друг с другом.

## Запуск

Скачайте репозиторий и откройте `particle-streams-collision.html` в современном браузере. Сервер, установка зависимостей и сборка не нужны: приложение целиком находится в одном HTML-файле и работает локально.

## Возможности

- Настройка направления, скорости, радиуса, разброса и частоты рождения частиц отдельно для каждого потока.
- Управление отношением масс, упругостью и шероховатостью столкновений.
- Четыре готовых сценария: встречные потоки, перекрёстное столкновение, тяжёлые и лёгкие частицы, плотный поток.
- Пауза, пошаговое продвижение и изменение скорости времени.
- Отображение траекторий, прямоугольные стенки и стенки, форма которых строится вдоль потоков.
- Перемещение и масштабирование сцены; отображение частиц на Canvas.
- Детерминированный генератор случайных чисел с фиксированным начальным зерном.

## Управление

| Действие | Управление |
| --- | --- |
| Переместить сцену | Зажать левую кнопку мыши и двигать указатель |
| Масштабировать сцену | Колесо мыши; клавиши `+` и `-` |
| Пауза / продолжить | Кнопка «Пауза» или `Пробел` |
| Сбросить частицы | Кнопка «Сброс» или `R` |
| Выполнить один шаг | `S` |
| Вернуть исходный вид | `F` |
| Остановить / возобновить рождение частиц | Кнопка «Остановить генерацию» |

Клавиши также распознаются при включённой русской раскладке (`К`, `Ы`, `А` соответствуют `R`, `S`, `F`). Настройки потоков и физики находятся в боковой панели «Параметры».

## Физическая модель

Частицы моделируются как круги с массой, линейной и угловой скоростью. Столкновения учитывают коэффициент восстановления по нормали и касательный импульс, зависящий от шероховатости. Для поиска пар используется пространственный хэш; проверка пересечения траекторий за шаг помогает обнаруживать столкновения быстрых частиц. Интегрирование выполняется с фиксированным шагом.

При одновременных столкновениях нескольких частиц контакты разрешаются последовательно, поэтому такая ситуация является приближением модели. При достижении лимита частиц генерация ограничивается; интерфейс показывает предупреждение.

## Технологии

- HTML, CSS и JavaScript без сторонних библиотек.
- Canvas 2D для сцены и частиц.
- `requestAnimationFrame` для цикла анимации.
